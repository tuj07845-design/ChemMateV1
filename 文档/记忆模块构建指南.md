## 1　现状：你的系统为什么"没有记忆"

先看现在的代码在"记忆"上做了什么、没做什么：

**已有的（记忆的雏形）**：
- `draw_mat.py` 里有个全局变量 `_LAST_PROCESS_DATA`，`remember_process_data()` 存、`get_cached_process_data()` 取——这是"**进程内缓存**"：一次运行中，取数结果给分析和绘图复用。
- 主程序 `run_agent` 里有个局部变量 `_last_data_get_result`，同一轮任务里 data_get 的结果自动注入 analyze/draw。

**没有的（真正的记忆）**：
1. **任务结束就忘**：`run_agent` 里的 `prompt_history`（对话过程）是局部变量，函数一返回就没了。你追问"再帮我生成 PDF 版"，它完全不记得刚才的分析。
2. **进程退出就清空**：`_LAST_PROCESS_DATA` 存在内存里，关掉 Python 就没了。
3. **跨任务零经验**：这次任务学会了"B7 闪蒸塔有压力报警"，下次任务它还是一张白纸。
4. **无法回放排查**：跑了 20 轮工具调用，中间发生了什么，没有任何记录。

> 一句话总结现状：**它只有"一次运行内的临时缓存"，没有"跨任务的记忆"**。这一篇就是教你把记忆建起来。

## 3　第一层：进程内短时记忆 `process_cache.py`

### 3.1 是什么

**作用：一次 Agent 运行中，跨工具共享数据。** 现在主要存"最近一次 data_get_process 的完整结果"，`analyze_process` / `draw_mat` 不显式传参时自动从这里取，避免大 JSON 反复传参。

这是你项目里已有的东西，我们把它**从 draw_mat.py 里搬出来、做规范**（不搬也行，但放在 memory 里更符合"记忆归 memory 管"的分层）。

### 3.2 代码（放在 `CMV1/memory/process_cache.py`，照抄）

~~~python
# -*- coding: utf-8 -*-
"""记忆层·第一层：进程内短时记忆（缓存）。

作用：一次 Agent 运行中，跨工具共享数据。
主要存"最近一次 data_get_process 的完整结果"，
analyze_process / draw_mat 不显式传参时自动从这里取。

特点：存在内存里，进程退出即清空（临时记忆）。
"""
_LAST_PROCESS_DATA = None
_HISTORY = []          # 最近 N 次取数历史（可选功能）


def remember_process_data(data, keep_history=False):
    """保存最近一次取数结果，返回原值（方便链式调用）。"""
    global _LAST_PROCESS_DATA
    _LAST_PROCESS_DATA = data
    if keep_history:
        _HISTORY.append(data)
        if len(_HISTORY) > 10:          # 最多留 10 条，防止内存膨胀
            _HISTORY.pop(0)
    return data


def get_cached_process_data():
    """取回最近一次结果；没有则返回 None。"""
    return _LAST_PROCESS_DATA


def get_history():
    """取历史列表（副本，防止外部误改）。"""
    return list(_HISTORY)


def clear():
    """清空缓存（任务开始前可调用，保证干净开始）。"""
    global _LAST_PROCESS_DATA
    _LAST_PROCESS_DATA = None
    _HISTORY.clear()
~~~

## 4　第二层：会话记忆 `session_store.py`（JSONL 文件）

### 4.1 是什么

**作用：把一次 Agent 任务的完整过程持久化到文件**，任务跑完后还能：
- 回放：出了错，打开文件看每一步（模型想了什么、调用了什么工具、工具返回了什么）；
- 续跑/参考：下次任务开始时，把上次的最终答案拼进提示词，让模型"记得上次的结果"。

**为什么用 JSONL 而不是 JSON？**
JSONL = 每一行一个 JSON 对象。日志天然是一行一条记录，用 JSONL 追加写入最简单（不用像 JSON 那样整个文件读进来再写回去），也方便用记事本看。

### 4.2 代码（放在 `CMV1/memory/session_store.py`，照抄）

~~~python
# -*- coding: utf-8 -*-
"""记忆层·第二层：会话记忆（JSONL 文件持久化）。

作用：把一次 Agent 任务的完整过程记到文件里：
    - 用户请求（role: user）
    - 每一轮的模型思考与行动（role: thought / action）
    - 工具返回结果（role: observation）
    - 最终答案（role: result）

文件位置：CMV1/runs/session_<会话号>.jsonl
"""
import json
import uuid
from datetime import datetime
from pathlib import Path

RUNS_DIR = Path(__file__).resolve().parent.parent / "runs"


def new_session():
    """开始一个新会话，返回 session_id。"""
    RUNS_DIR.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    session_id = stamp + "_" + uuid.uuid4().hex[:6]
    return session_id


def _log_path(session_id):
    return RUNS_DIR / ("session_" + session_id + ".jsonl")


def record(session_id, role, content):
    """记一条记录。role 取值：user / thought / action / observation / result。"""
    entry = {
        "ts": datetime.now().isoformat(timespec="seconds"),
        "session": session_id,
        "role": role,
        "content": content,
    }
    path = _log_path(session_id)
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(entry, ensure_ascii=False) + "\n")


def load_session(session_id):
    """读回一个会话的全部记录（列表，每条是 dict）。"""
    path = _log_path(session_id)
    if not path.exists():
        return []
    records = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                records.append(json.loads(line))
    return records


def last_answers(session_id, n=3):
    """取最近 n 条最终答案（role=result），供下次任务参考。"""
    records = load_session(session_id)
    answers = [r["content"] for r in records if r.get("role") == "result"]
    return answers[-n:]
~~~

## 5　第三层：长期知识库 `knowledge_base.py`（知识卡）

### 5.1 是什么

**作用：跨会话、跨任务的"经验仓库"。** 把化工知识、踩坑记录、工具用法写成一张张 **Markdown 知识卡**，Agent 遇到问题时按关键词检索，把相关卡片内容拼进提示词——这样它就"用得上以前的经验"了。

**先建几张卡试试**（放 `CMV1/memory/knowledge/` 目录，一张卡一个 .md 文件，文件名用英文或拼音）：

`CMV1/memory/knowledge/b7-flash.md`：

~~~markdown
# B7 闪蒸塔压力报警处理

> 标签：闪蒸塔 压力 报警 B7

现象：10万吨环己烷流程中 B7 (Flash2) 常报压力过高。

原因排查顺序：
1. 检查进料流量是否突然增大
2. 检查塔顶气相出口是否堵塞
3. 检查温度设定是否偏高导致气化量增加

处置：先人工确认，再让 Agent 修改参数，修改前必须向用户确认。
~~~

`CMV1/memory/knowledge/tool-usage.md`：

~~~markdown
# 工具使用要点

> 标签：工具 draw_mat data_get 用法

- data_get_process 返回结果很大，不要直接全部塞进对话，用摘要。
- draw_mat 画图前必须已有 data_get_process 的结果（记忆缓存里有）。
- report_create 的 sections 支持 heading / paragraph / bullets / table / image。
~~~

### 5.2 代码（放在 `CMV1/memory/knowledge_base.py`，照抄）

~~~python
# -*- coding: utf-8 -*-
"""记忆层·第三层：长期知识库（经验/知识卡）。

作用：跨会话的"经验仓库"。把知识写成一张张 Markdown 知识卡，
Agent 需要时按关键词检索，把相关卡片拼进 system prompt。

知识卡目录：memory/knowledge/*.md
卡片格式：
    # 标题
    > 标签：关键词1 关键词2
    正文...
"""
import re
from pathlib import Path

KNOWLEDGE_DIR = Path(__file__).resolve().parent / "knowledge"


def ensure_dir():
    """确保知识库目录存在（第一次用时自动创建）。"""
    KNOWLEDGE_DIR.mkdir(parents=True, exist_ok=True)


def add_card(filename, title, tags, body):
    """新建/覆盖一张知识卡。filename 例如 'b7-flash.md'。"""
    ensure_dir()
    path = KNOWLEDGE_DIR / filename
    text = "# " + title + "\n\n> 标签：" + tags + "\n\n" + body + "\n"
    path.write_text(text, encoding="utf-8")
    return path


def list_cards():
    """列出所有知识卡的名字。"""
    ensure_dir()
    return sorted(p.stem for p in KNOWLEDGE_DIR.glob("*.md"))


def search(keywords, top_k=3):
    """按关键词在卡片标题/标签/正文里检索，返回 [(卡片名, 全文), ...] 按相关度排序。"""
    ensure_dir()
    if isinstance(keywords, str):
        keywords = [keywords]
    results = []
    for path in KNOWLEDGE_DIR.glob("*.md"):
        text = path.read_text(encoding="utf-8")
        score = 0
        for kw in keywords:
            score += len(re.findall(re.escape(kw), text))
        if score > 0:
            results.append((score, path.stem, text))
    results.sort(key=lambda x: -x[0])          # 相关度高的排前面
    return [(name, text) for score, name, text in results[:top_k]]


def build_knowledge_context(query=None, max_chars=1500):
    """检索相关知识卡并拼成一段文字，可直接塞进 system prompt。没有命中就返回空串。"""
    if not query:
        return ""
    cards = search(query)
    if not cards:
        return ""
    parts = ["# 参考资料（来自长期记忆知识库）", ""]
    total = 0
    for name, text in cards:
        if total > max_chars:
            break
        parts.append(text)
        total += len(text)
    return "\n\n".join(parts)
~~~

> 小白解释：`re.findall(re.escape(kw), text)` = "数一数这段文字里这个关键词出现了几次"，出现越多相关度越高。这是最简单的检索；知识卡多了以后再升级成向量检索（第 8 节）。

## 6　接入主程序 `agent_main.py`（关键步骤）

三层都建好后，把它们接进主程序。**只改 `agent_main.py` 一个文件**，分三处：

### 6.1 第一层：缓存接入（原来就有，改成从 memory 导入）

主程序里 data_get 成功后保存结果的地方（原来调 draw_mat 的 `remember_process_data`），改成：

~~~python
from memory.process_cache import remember_process_data, get_cached_process_data
~~~

调用处不变：`remember_process_data(observation)`。想保证"每次任务干净开始"，在 `run_agent` 开头加：

~~~python
from memory.process_cache import clear
clear()          # 清空上次的取数缓存，这次任务重新开始
~~~

### 6.2 第二层：会话记忆接入

`run_agent` 里加 4 处：

~~~python
from memory.session_store import new_session, record, last_answers

def run_agent(task, max_rounds=20, stop_event=None, log=None, session_id=None):
    # 1. 开始会话（没给 session_id 就新建一个）
    if session_id is None:
        session_id = new_session()

    # 2. 可选：把上次任务的最终答案拼进来，让模型"记得上次结论"
    prev = last_answers(session_id)
    if prev:
        print("引用上次任务结论:", prev[-1])

    # 3. 记录用户请求
    record(session_id, "user", task)
    ...
    # 4. 在每一轮的关键位置追加记录：
    #    模型输出后：  record(session_id, "thought", llm_output)
    #    工具结果后：  record(session_id, "observation", observation_str)
    #    Finish 时：   record(session_id, "result", final_answer)
~~~

> 实际操作提示：原来 `_emit(...)` 打印日志的地方，加一行对应的 `record(...)` 即可（`_emit` 是打印到屏幕，`record` 是写到文件，两者互补）。
> 想支持"追问"（比如上次跑完你继续问"再生成 PDF"），在 UI 或命令行入口把上次的 `session_id` 传进来即可。

### 6.3 第三层：知识库接入（在拼 system prompt 时注入）

调用 `llm.generate` 前，把检索到的知识拼进 system prompt：

~~~python
from memory.knowledge_base import build_knowledge_context

def run_agent(task, ...):
    ...
    # 从用户任务里挑 1-3 个关键词（最简单：整句丢进去让代码自己数词频）
    knowledge = build_knowledge_context(task, max_chars=1200)
    sys_prompt = AGENT_SYSTEM_PROMPT
    if knowledge:
        sys_prompt = AGENT_SYSTEM_PROMPT + "\n\n" + knowledge
    ...
    llm_output = llm.generate(full_prompt, system_prompt=sys_prompt)
~~~

> 效果：用户问"B7 压力报警"，知识库里正好有这张卡，模型就会照着卡里的排查顺序走，而不是瞎猜。**这就是"Agent 有经验了"。**

## 8　进阶方向（了解即可，现在不用做）

1. **向量检索**：知识卡多了以后，关键词匹配不够准。可以给每张卡生成"向量"（用 embedding 模型），检索时算相似度。Python 里可用 `chromadb` 或 `faiss`，网上搜"chromadb 中文文档"有教程。
2. **记忆遗忘策略**：长期记忆不是越多越好，可以按"使用次数 + 最近使用时间"给卡片打分，低分的自动降级。
3. **结构化存储**：会话历史多了之后，JSONL 文件会很多，可以改用 SQLite（一个 .db 文件，自带查询）。Python 自带 `sqlite3`，不用装包。
4. **多轮对话界面**：现在的入口是"一次任务一问"。接第二层会话记忆后，可以把 UI 改成"同一个 session_id 连续追问"，形成真正的对话记忆。

> 记住核心思路：**第一层让工具间不传大 JSON，第二层让任务可回放可续接，第三层让 Agent 有经验**。这三层搭起来，你的 ChemMate 就从"一次性工具"升级成"有记忆的助手"了。
